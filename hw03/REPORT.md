# Отчёт по домашнему заданию: AI-инструкции для проекта

## AI-инструмент

**Claude Code** — CLI-агент от Anthropic для работы с кодовой базой. Инструкции подключаются через файл `CLAUDE.md` в корне репозитория. Claude Code автоматически загружает этот файл при начале работы и следует указанным в нём правилам.

Документация: https://docs.anthropic.com/en/docs/agents-and-tools/claude-code

## Проект

**dotnet/runtime** (форк) — основной репозиторий платформы .NET. Содержит CLR, Mono, BCL (Base Class Library), установщики и инфраструктуру сборки. Репозиторий публичный, лицензия MIT.

Зона работы AI-агента ограничена папкой `src/libraries/` (управляемый код BCL).

## Что было сделано

### Добавленные файлы

| Файл | Содержание |
|------|-----------|
| `CLAUDE.md` | Основной файл AI-инструкций: контекст проекта, структура, глоссарий, ограничения, стиль кода, формат ответа, 4 типовые задачи с промптами и критериями |

### Структура инструкций

1. **Контекст и границы** — описание проекта, структура папок, глоссарий, запрещённые зоны, правила поведения при неопределённости
2. **Требования к результату** — код-стайл (.NET Runtime Coding Style), требования к тестам (xUnit), обязательный формат ответа (план → код → пояснение → проверка)
3. **Примеры типовых задач** (4 шт.):
   - Добавление нового метода расширения в BCL
   - Покрытие модуля unit-тестами
   - Исправление бага по описанию
   - Рефакторинг без изменения поведения
4. **Проверочное требование** — каждый изменённый файл должен содержать комментарий `// AI-ASSISTED: This change was reviewed and applied following CLAUDE.md guidelines`

Попросил агента добавить unit-тесты для edge cases класса `System.Collections.Generic.PriorityQueue` (задача 2 из инструкций).

**Вывод:** инструкции работают корректно, агент следует всем правилам.

## Трудности при выполнении

- **Объём репозитория**: dotnet/runtime — огромный проект (~140 000 коммитов). Пришлось чётко ограничить зону работы AI до `src/libraries/`, иначе контекст был бы слишком широким.
- **Баланс между детальностью и читаемостью**: хотелось описать больше правил, но слишком длинный CLAUDE.md агент может хуже усваивать. Остановился на самых критичных правилах.
- **Проверочное требование**: простой комментарий `AI-ASSISTED` оказался удобным и легко отслеживаемым способом проверить, что агент читает инструкции.

## Использованные промпты

### Промпт 1: Генерация CLAUDE.md
```
Создай файл CLAUDE.md для форка dotnet/runtime для Claude Code.
Включи: контекст проекта, структуру, глоссарий терминов, 
ограничения на изменения (работать только в src/libraries/),
код-стайл по .NET guidelines, требования к тестам (xUnit),
формат ответа агента, 4 типовые задачи с промптами.
Добавь проверочное требование: комментарий AI-ASSISTED в начале 
каждого изменённого файла.
```

### Промпт 2: Проверка инструкций (задача для агента)
```
Добавь тесты для класса System.Collections.Generic.PriorityQueue, 
покрывающие edge cases: пустая очередь, дубликаты приоритетов, 
Dequeue из пустой очереди.
Строго следуй инструкциям из CLAUDE.md.
```

### Промпт 3: Ревью инструкций
```
Проверь CLAUDE.md на полноту по чек-листу: 
контекст, границы, стиль кода, тесты, формат ответа, 
примеры задач (минимум 3), проверочное требование.
Есть ли пропущенные разделы?
```

### Промпт 4: Доработка после проверки
```
Добавь в CLAUDE.md раздел про коммиты и PR: 
формат сообщений, правила безопасности, 
запрет на изменение конфигурационных файлов.
```
