# Журнал изменений

## 2026-02-02 - Гарантированное сохранение отчётов

### Изменения
Оба скрипта переименования (`rename_with_kinopoisk.py` и `rename_movies_russian.py`) теперь **ВСЕГДА** сохраняют отчёт о проделанной работе.

### Что изменилось?
- ✅ Добавлен блок `try-except-finally` в функцию `main()`
- ✅ Отчёт сохраняется в блоке `finally`, который выполняется ВСЕГДА
- ✅ Отчёт сохраняется даже при:
  - Прерывании скрипта пользователем (Ctrl+C)
  - Возникновении ошибок во время работы
  - Исключениях в коде

### Зачем это нужно?
После выполнения скрипта (даже частичного) вы получите отчёт с таблицей:
- **Колонка "Было"** - оригинальное название файла
- **Колонка "Стало"** - новое название файла
- **Колонка "Статус"** - статус операции

Это позволяет:
1. Найти оригинальные названия файлов
2. Увидеть какие файлы были обработаны до прерывания
3. Вручную исправить проблемные случаи
4. Отследить прогресс переименования

### Примеры сохраненных отчётов
- `rename_report_kinopoisk.md` - для скрипта с Кинопоиском
- `rename_report.md` - для базового скрипта переименования

### Пример использования
```bash
# Dry-run (только показать, что будет сделано)
python rename_with_kinopoisk.py --dry-run

# Реальное переименование
python rename_with_kinopoisk.py --execute

# С указанием пути к отчёту
python rename_with_kinopoisk.py --execute --output my_report.md
```

### Структура отчёта
Отчёт содержит:
- Статистику по всем операциям
- Таблицу с оригинальными и новыми названиями
- Информацию об ошибках и пропущенных файлах
- Пути к файлам для ручной корректировки

Это особенно полезно когда нужно:
- Откатить изменения
- Найти конкретный файл по старому имени
- Вручную исправить неправильно переименованные файлы
