# Changelog

## [2.4.0] — 2024-02-01

### Добавлено
- Drag-and-drop задач между колонками на доске спринта (React DnD Kit)
- WebSocket уведомления о смене статуса задачи в реальном времени
- Фильтр задач по нескольким меткам одновременно (AND/OR логика)

### Исправлено
- Исправлена утечка памяти в Notification Service при большом количестве WebSocket-соединений
- Корректная обработка таймзон при отображении дедлайнов (используется UTC на бэкенде, локальное время на фронте)

### Изменено
- Обновлён FastAPI с 0.104 до 0.109 (breaking: deprecated `on_event`, переход на `lifespan`)
- Миграция фронтенда с React Query v4 на TanStack Query v5

## [2.3.0] — 2024-01-15

### Добавлено
- Экспорт задач проекта в CSV
- Кастомные поля задач (текст, число, дата, select) — настраиваются на уровне проекта
- Bulk-операции: смена статуса и назначение для нескольких задач

### Исправлено
- N+1 запрос при загрузке задач с labels (добавлен selectinload)
- Race condition при одновременном обновлении задачи двумя пользователями (добавлен optimistic locking через version_number)

## [2.2.0] — 2023-12-20

### Добавлено
- Спринты: создание, управление бэклогом, burndown chart
- Activity log доски: кто, когда, какое действие выполнил
- Полнотекстовый поиск задач через PostgreSQL tsvector

### Изменено
- Переход с синхронного SQLAlchemy на asyncpg (производительность +40% на нагрузочных тестах)
- Docker Compose: добавлены healthcheck для всех сервисов

## [2.1.0] — 2023-11-10

### Добавлено
- Комментарии к задачам с Markdown-рендерингом
- Email-уведомления о назначении задачи и новых комментариях
- Rate limiting на API Gateway (100 req/min per user)

### Исправлено
- JWT refresh token rotation работает корректно при параллельных запросах

## [2.0.0] — 2023-10-01

### Добавлено
- Микросервисная архитектура (разделение монолита на 4 сервиса)
- Kong API Gateway
- RabbitMQ для межсервисного взаимодействия
- Kubernetes деплой (Helm charts)

### Breaking Changes
- API endpoint paths изменены: `/tasks` → `/api/tasks/tasks`
- Аутентификация через JWT вместо session cookies
- Формат ответа пагинации: `{items, total, page, per_page}` вместо массива
