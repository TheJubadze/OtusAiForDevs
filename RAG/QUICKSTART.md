# Быстрый старт

Два варианта установки — выберите подходящий:

## [QUICKSTART_LITE.md](QUICKSTART_LITE.md) — Рекомендуемый

**RAG + Claude (без локальной LLM)**

- Ollama нужна **только для эмбеддингов** (274 MB)
- Ответы генерирует **Claude** — качество гораздо выше
- Скачивать: ~274 MB
- Время установки: ~20 мин

Подходит, если вы работаете с Claude через VS Code (Claude Code) и у вас есть интернет.

---

## [QUICKSTART_FULL.md](QUICKSTART_FULL.md) — Полная версия

**RAG с локальной LLM (полностью автономный)**

- Ollama для эмбеддингов (274 MB) **+ LLM** qwen2.5:3b (2 GB)
- Ответы генерирует **локальная модель** — всё работает без интернета
- Скачивать: ~2.7 GB
- Время установки: ~25 мин

Подходит, если вам нужен полностью автономный RAG (без Claude API), или для демонстрации Corrective RAG пайплайна.
